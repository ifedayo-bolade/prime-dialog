(v1.0.0)
- Initial release.

(v1.0.1)
- Removed unused resources
- Removed 'setWindowAnimationEnabled(boolean)'
- Added 'setDontShowAgainColor()' and 'setDontShowAgainColorRes()'.
- Added built-in window enter and exit animation style resources:
    'PrimeDialog.WINDOW_ANIMATION_FADE'
    'PrimeDialog.WINDOW_ANIMATION_FLASH' -> (Used as default)
    'PrimeDialog.WINDOW_ANIMATION_SLIDE'
to be used with 'setWindowAnimation(styleRes)'.
- Fixed title typeface not getting applied with 'setTitleTypeface()' and 'setTitleTypefaceRes()'.

(v1.0.2)
- Renamed 'setMessageMargin()' to 'setMargin()'
- Ability to set custom layout/view margins by calling 'setMargin()'
- Added 'removeDontShowAgain(key)' for use with a dialog instance
- Added 'PrimeDialog.removeDontShowAgain(context, key)' and
    'PrimeDialog.removeDontShowAgain(context, List<key>)'for use with no dialog instance
- Added 'setManagedDontShowAgain(key, label, onDontShowAgainListener)'
- Added 'OnDialogSuppressedListener' to intercept an attempt to show dialog after
    'Don’t show again' has taken effect.
- Added 'setHeaderBitmap(bitmap)' and 'setHeaderDrawable(drawable)'
- Renamed 'setHeaderBackgroundRes(drawableRes)' to 'setHeaderDrawable(drawableRes)'
- Renamed 'setHeaderBackgroundColor()' to 'setHeaderColor()'
